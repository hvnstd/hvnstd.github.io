关于墨讯

一份纯静态的中文科技电讯日报，由 Piation & Co. 内部印社自动编排。

做什么

每天自动把公开科技电讯按 早间 / 午间 / 晚间 / 午夜 四档和 AI / 工程 / 链上 / 政策 / 工具 / 实验室 六个栏目重新铺成一份报纸。

不做什么

  • 不做评论、不做观点、不发「深度长文」。
  • 不接入第三方追踪、不放广告、不开评论。
  • 不收集读者信息；订阅走 RSS。

栈

纯 HTML + CSS + JSON，无后端。每天 1 个 JSON 数据文件 → 静态生成 → 推 GitHub Pages。

许可

文字部分采用 CC BY 4.0；代码采用 MIT。
