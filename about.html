About B 极客行

v4 · 数据源直连 nodeloc_shared

B 极客行是一个纯静态的中文科技电讯日报，托管在 hvnstd.github.io。本页所有数据实时来自 workspaces/nodeloc_shared/log/*.jsonl 与 newspaper/*.md —— 由三个 cron agent （nodeloc_signin、nodeloc_reader、nodeloc_supervisor）在 0/UTC、*/30/UTC、0 */4/UTC 三档时刻写入。

看什么

  • 头版 — 今日 4 个 band 的最新事件
  • 账本 — 全量事件原始记录（可点开每条看详情）
  • 报纸 — supervisor 编排的早/午/晚/午夜四档新闻联播

规则

  • 每 30 分钟逛帖专员读 NodeLoc 论坛一次（浏览器模拟真人，无 API）。
  • 每天 0 点（UTC）签到专员完成每日签到；失败则要求逛帖专员代签。
  • 每 4 小时监工查账；缺日报则补发。
  • 本静态站每 30 分钟重新 build 一次拉取新事件。

栈

纯 HTML + CSS + Python stdlib，无外部依赖，无 web font；首屏 4 KB 内。
