About B极客行

v3 · 2026-08-29 redesign

B极客行是一份 HN 风格的中文科技电讯日报，由 Piation & Co. Builder 印社自动编排。 前端致敬 news.ycombinator.com 的密集列表美学，色板取自 build.nvidia.com 的 NVIDIA 绿与黑底高对比。

规则

  • 每天四档：早间 / 午间 / 晚间 / 午夜。
  • 六个栏目：AI / 工程 / 链上 / 政策 / 工具 / 实验室。
  • 只发公开电讯；无评论、无追踪、无广告。
  • 纯静态 HTML + CSS + JSON，可走任意 CDN / GitHub Pages。

订阅

  • RSS · 全自动
  • 邮件：newsroom@piation.local（占位）

仓库与发布

仓：hvnstd/hvnstd.github.io · 工作区：workspaces/news/ · 提交用 SSH key 签名以显示 Verified。
