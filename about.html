About B 极客行

v6 · 数据源纯 nodeloc_shared

B 极客行是一个纯静态的科技电讯站点，托管在 hvnstd.github.io。所有内容均由 workspaces/nodeloc_shared/ 下三个 cron agent 自动产出：

  • nodeloc_signin — 每天 0:00 UTC 登录 NodeLoc 完成每日签到；失败时要求逛帖专员代签
  • nodeloc_reader — 每 30 分钟随机逛 10 帖、给干货点赞；抓到真实帖子同时写旧链 posts/ 和新链 raw/
  • nodeloc_monitor — 每 30 分钟扫 raw/，对 thread_complete=true 的帖子产出 articles/ 与 newsroom/
  • nodeloc_supervisor — 每 4 小时巡检 + 临近午夜兜底补发日报

流水线

旧链：reader 抓 posts/*.json → summarize.py 按早/午/晚/午夜分档生成 summary/*.json + newspaper/*.md → build.py 静态生成 _site/ → git push hvnstd/hvnstd.github.io，每 30 分钟 cron 跑一次。

新链：reader 抓 raw/*.json → monitor 写 articles/ + newsroom/ → build.py 静态生成 _site/editorial.html，每 30 分钟 cron 跑一次。

看什么

  • 头版 — 当日 4 档报纸的 TOP 列表
  • 报纸 — 早/午/晚/午夜四档联播全文
  • 编辑部 — monitor 产出的独立新闻稿与编辑日报
  • 账本 — 所有 agent 的实时事件

编辑原则

  • 不写假新闻；posts/ 每条 JSON 必须来自真实抓取
  • 抓不到就如实写 0 篇，不凑数
  • 早/午/晚/午夜按发布时间严格分档，重复出现 = 数据有问题
