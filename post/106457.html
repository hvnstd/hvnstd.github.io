【9.5更新】M365-CF稳定版（修复诸多问题）

https://www.nodeloc.com/t/topic/106457 · n/m365-copilot
早间·09:45 |40 分 |77 评论 |by TXT

OP（TXT）发布 M365-Gateway-CF4 9.5 稳定版：CF 部署无需服务器；修复 Codex 0.153.2 Responses Lite 兼容、previous_response_id 多轮对话续接、无状态工具续接、exec_command/write_stdin、Windows PS 特殊字符、长任务上下文保持；支持 Chat Completions/Responses/Anthropic Messages、Claude thinking 映射、tool_mode=code_mode_only、multi_agent_version=v2；适配 codex-cli/opencode/Claude/herme；附 9.4/9.5 开源 ZIP。

原文摘录

OP（TXT / asdzxc252）2 天前发帖，M365 Copilot 板块 AI 标签。

注意事项：让 AI 部署（CF 部署，无需服务器 / 本地部署）。问题反馈 QQ 群：35337083。

9.5 修复 / 新增清单：
- 修复 Codex 0.153.2 的 Responses Lite 兼容
- 支持 tool_mode=code_mode_only
- 支持 multi_agent_version=v2
- 保留旧版客户端使用的 direct 路径，避免升级后旧客户端失效
- 修复 previous_response_id 多轮对话续接
- 修复无状态工具续接
- 修复 exec_command 和 write_stdin 工具调用流程
- 修复 Windows PowerShell 命令中的特殊字符和变量传输
- 修复长任务、网页构建和多步工具执行时的上下文保持
- 支持 Chat Completions、Responses 和 Anthropic Messages 三套接口
- 支持 Claude thinking 参数映射到内部深度推理路由（暂不公开完整隐藏思维链）
- 增加工具调用安全检查，避免重复执行、伪造本地执行成功或错误地使用托管环境替代本地工具
- 增强流式响应、取消请求、超时、账号切换和会话状态处理
- 将较重的推理处理放入 InferenceGateway Durable Object，降低 Worker 入口 CPU 压力

常见错误：503 / 502 / 1101 / 413 — 重开或等几分钟解决。

长任务最好跑 /goal 内容。

适配：codex + cli / opencode / Claude / herme。

- 9.4：M365-Gateway-open-source-20260904.zip（545.6 KB）
