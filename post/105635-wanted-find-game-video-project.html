这个项目是一个收游戏视频的一个项目：它会给你一个 OBS 伴侣（录制键鼠的），然后玩家录制完提交到在线文档里，后面通过 AI 审核有效时长发钱。
目前拥有的线索：1）一个下游的群，群主是下游、管理员貌似是上游，可以从管理员入手（Q群 2167070588）；2）推测这个项目可能是某 AI 公司或其空壳公司在做（几百万投入不像小团体）；3）存在一个可查看审核进度的后台；4）持续更新实质性线索。
楼中关键线索（user80 贺煦修）：字节跳动 Seed 团队 Lumine 论文（arXiv 2511.08892v1）Appendix 10.3 明确写到标注过程会录制标注者屏幕活动与键鼠交互，并自研游戏数据录制软件、用 Win32 API SetWindowsHook 全局钩子采集键盘与鼠标坐标；法本信息公开承认与字节合作包含数据标注、采集服务、ITO 外包；字节亦有众包平台「竹节」，2025 年 3 月公开招标寻找垂类标注供应商。另提供 Xpert 专家社区（corexpertdata.com）、模兜（zhujie100.com）等渠道线索。
