DeepSeek Harness 插件装之前，我现在会先检查这几件事

最近折腾 DeepSeek Harness 插件比较多，慢慢发现一个问题：「GitHub 上有这个插件」和「这个插件现在能正常装、适合装」完全是两回事。装陌生插件前现在都会先看一遍几个东西。

原文摘录

楼主 susu su 分享装 DeepSeek Harness（DSH）插件前的自查清单：①确认安装方式（npm 包/GitHub 仓库是否还在、近期是否更新、是否需要 build、有无 install script）；②能安装成功比 Star 数更重要（DSH 生态新，常遇包不存在、依赖对不上、build 出错、新版不兼容）；③看是否碰 terminal，风险分级：只读 API < 写入外部服务 < 文件系统 < Terminal/Shell；④Credentials（API_KEY/TOKEN/COOKIE/ACCOUNT 存哪、是否仅本地、发到哪个域名、日志会不会输出、有无 telemetry，可搜 process.env / fetch / axios / telemetry / analytics）；⑤「没发现风险」不等于「安全」；⑥最后才看功能值不值得装。共 2 回复、52 浏览、1 赞。属干货帖。
