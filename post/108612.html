活动期间注册、此前没有充值记录的账号；
额度有效期 7 天，每个账号限领一次；
到账后可用于账户允许的模型调用，先体验再决定是否充值。
活动前已经注册，或账号已有充值记录；
优惠券有效期 7 天，每个账号限领一次；
符合用券条件的 ¥20 充值订单，使用后实付 ¥15。
两类评论奖励按账号资格领取对应一项。评论核对通过后，奖励会发到账户，并通过站内消息通知；适用范围及其他优惠能否叠加，以到账券详情和结算页为准。请勿在评论区发布邮箱、密码或 API Key。

按量调用可在模型广场查看输入、输出和缓存价格，根据实际使用扣除平台额度。

会员不自动续费，使用独立 API Key；周期总额度与每 7 日窗口额度同时生效。会员可用模型及扣费价格以会员页面为准，上方按量价格表不代表会员模型池的扣费标准。
企业或工作室可以申请专享号池：独立 API Key、独立模型分组和独立额度统计，仅供本企业或工作室自己的用户使用。可以按团队人数、模型范围、并发需求和预算沟通配置。
