如何获得一个图床（建站三件套第三套）

原文摘录

上篇写了邮件系统了，这篇就该写图床了（用我最喜欢的cloudflare部署大法）。这个项目是别人告诉我的但不是我的，所以写错了帮我指正一下哈。

1. 准备
1.1 登录 cloudflare（略）
1.2 fork github 项目：MarSeventh/CloudFlare-ImgBed（🏖️ A serverless, open-source file hosting solution built on Cloudflare. 支持图床、安全文件存储与个人云盘）。

2. 部署
2.1 部署 Pages：打开 计算-Workers和Pages → 点击创建应用程序 → 下方小字使用 Pages → 点击导入现有 git 存储库 → 选择账户与 fork 的仓库 → 点击开始设置。项目名称自定义，生产分支 main，构建命令 npm install（不要被老教程误导），构建输出目录 /frontend-dist。然后点击保存并部署，等待部署即可。

3. 绑定 KV（D1 也行，推荐 KV）
3.1 打开 存储和数据桶 - Workers KV，创建名为 img_url 的 KV。
3.2 绑定：回到 Pages，在设置里绑定那个 KV，名称为 img_url。

4. 重新部署：去部署页，找到最新部署点击重新部署。

5. 配置：去 你的网址/dashboard → 系统设置 → 左侧安全设置，密码设上（一个上传用，一个登录管理台用）→ 左侧上传设置，随便选一个并配置（作者选的 TG）。然后就可以快乐使用图床了，不再用网盘存图被屏蔽。
