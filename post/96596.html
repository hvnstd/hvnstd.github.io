Lunes Host 自动保活脚本

OP 分享 Lunes Host（betadash.lunes.host）自动保活脚本：GitHub Actions 定时登录、处理 Cloudflare 整页挑战 + Turnstile 验证、跳转服务器详情页完成保活、内建 20 次/小时速率限制、支持 Hysteria2 代理与 Telegram 通知（带截图）。

原文摘录

OP（mc838，七转八起，6月28日）分享 Lunes Host 自动保活脚本：
- 注册地址：https://betadash.lunes.host/
- 行为：定时登录 Lunes Host 并访问服务器页面，保持账号活跃，避免长时间不活动被暂停；
- 绕过：自动登录并处理 Cloudflare 整页挑战 + Turnstile 验证；
- 完成后自动跳转至服务器详情页完成保活，"无服务器"场景智能识别仍视为保活成功；
- 安全：内建速率限制保护（20 次/小时阈值自动停止）；
- 通知：支持 Telegram Bot（带截图）；
- 代理：支持 Hysteria2 代理；
- 触发：定时 / 手动 / API 多种方式；
- 浏览器状态自动清理，避免 Cookie 干扰。

GitHub Secrets 配置（必填）：
- LUNES：Lunes Host 账号信息（邮箱-----密码格式）；
- HY2_URL：Hysteria2 代理地址（如 hysteria2://password@server:port?sni=example.com）。
选填：TG_BOT_TOKEN / TG_CHAT_ID 用于 Telegram 通知。

免责声明：本脚本仅供学习与自动化运维研究，使用者须遵守 Lunes Host 服务条款。
