原文摘录

heyuxuanyyds1 12 天前原创。第一篇虚拟主机 + 云服务器混合盘点：

1. rawhq（https://www.npmjs.com/package/rawhq）：npm install -g rawhq → raw init 邮箱注册 → raw deploy --type raw-free --region eu → 自动 Linux VM / root / 公网 IPv4。
2. Lunes：仅邮箱注册 → 控制面板 Create Server → 选德国或美国节点 → 免费套餐。每账号一台，每 15 天登录面板一次。
3. Serv00（https://www.serv00.com）：邮箱验证 → 控制台创建网站（PHP / Node.js / Python）+ 数据库 + 自定义端口 SSH。3 个月不登录清理。
4. Wasmer（https://wasmer.io）：控制台 Create app → GitHub 导入 / 上传文件夹 / 模板 → Hobby 免费 3 站点 / 自动 SSL / 自定义域名。
5. GearHost（https://www.gearhost.com）：Shared Web Node $0/月 → 0 元下单 → FTP / 数据库 / 自定义域名 / SSL。适合 .NET / PHP 小型项目。
6. 蓝队云（https://www.landui.com）：实名认证（支持支付宝快捷）→ 免费虚拟主机 → PHP + ASP + MySQL，不限流量并发。
7. Koyeb（https://www.koyeb.com）：邮箱注册无绑卡 → Create App from GitHub/Docker/源码 → Nano 免费套餐 → HTTPS / 自定义域名 / 不休眠。
8. Render（https://render.com）：GitHub/GitLab/Google 登录无信用卡 → New Web Service → Free → onrender.com 子域名 + SSL。Web 15 分钟休眠；免费 1GB PostgreSQL（30 天有效）。
