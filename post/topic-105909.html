原文摘录

上篇写了邮件系统了，这篇就该写图床了（用我最喜欢的cloudflare部署大法）。这个项目是别人告诉我的但不是我的，所以写错了帮我指正一下哈。

1.准备
1.1 登录cloudflare（略）。
1.2 fork github项目：MarSeventh/CloudFlare-ImgBed —— 一个基于 Cloudflare 的无服务器开源文件托管方案，支持图床、安全文件存储与个人云盘。

2.部署
2.1 部署pages：打开 计算-Workers和Pages，点击创建应用程序，点击下方小字使用 Pages，点击导入现有 Git 存储库，选择你的账户和刚才 fork 的仓库，点击下面的开始设置。项目名称自定义，生产分支 main，构建命令 npm install（不要被老教程误导了），构建输出目录 /frontend-dist，然后点击保存并部署，等待部署即可。

3.绑定 KV（D1 也行，不过推荐 KV）
3.1 打开 存储和数据桶-Workers KV，创建名为 img_url 的 KV；
3.2 绑定：回到那个 Pages，在设置里绑定那个 KV，名称为 img_url。

4.重新部署：去到部署页，找到最新的部署点击重新部署。

5.配置：去到你的网址 /dashboard，进入后找到系统设置，点进去；点击左侧的安全设置，密码设上（一个是上传图片用的，一个是登录管理台用的）；然后点击左侧的上传设置，随便选一个并配置（作者选的 TG）。然后，你就可以快乐地使用你的图床了，不会遭受用网盘存被屏蔽的问题。
