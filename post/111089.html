原文摘录

开发 Lipanel 的初衷很简单：市面上的服务器面板，有些随着功能不断增加而愈发臃肿，有些则采用相对封闭的插件生态。
我们希望做一款核心足够精简、支持插件化扩展，并且能够以单文件形式部署的 Linux 面板。
以下功能均已完成并通过实际运行验证：
systemd 服务管理
文件管理
网站管理，包括 Nginx 静态站点与反向代理
Let’s Encrypt SSL 证书自动申请与续期
采用 Unix Socket 与 HTTP 通信
支持权限声明和审计日志
插件前端默认启用 iframe 沙箱隔离
插件无法读取 Cookie，也不能直接调用面板 API
提供三级路径安全校验
命令统一通过 argv 参数切片执行，不拼接 Shell 命令
所有写操作均记录审计日志
敏感操作执行前进行权限判定
Go
Vue 3
Vite
Naive UI
目前生成的单个二进制文件约为
，通过
构建为纯静态程序，运行时无需依赖 Node.js、Python 或 Java。
权限模型的能力边界已在代码注释中明确记录：Lipanel 管理的是“面板转发通道”，并不将其描述为内核级沙箱。
软件商店，计划支持：
一键安装 PHP、Nginx 和 MySQL
指定安装版本
多源回退
应用商店
Docker 插件

欢迎试用并提交 Issue，也欢迎开发者参与官方插件的开发。

许可证开源。
