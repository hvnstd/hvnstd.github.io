【存档】免费白嫖日本/韩国原生家宽节点！基于 Serv00 + PHP 打造专属 Mihomo 订阅接口

晚间·04:01 |18 分 |15 评论 |by 1panel

原帖发在内版被系统过期自动隐藏了，看到有人还需要，就自己创建节点重新发表一次；利用薅来的 Serv00 免费服务器跑一段 PHP（openvpn.php），抓取 VPNGate 公开的家宽 .ovpn，自动转成 Mihomo 可用的 YAML 并加 1 小时文件缓存，直接当作订阅源；搭配前置节点即可在国内场景使用。

原文摘录

原帖发在内版被系统过期自动隐藏了，看到有人还需要，就自己创建节点重新发表一次，不喜直接划走
之前薅的 Serv00 免费vps服务器一直闲着不知道干点儿啥 不记得在哪里看到的，VPNGate 提供海量日本/韩国志愿家宽节点 VPNGate 官方仅提供原始 CSV 和单个 .ovpn 格式，无法直接给 Mihomo 使用 因此需要一个自动化转换层，这不就有了嘛，终于可以让 Serv00 派上用场了
废话不多说，直接上代码，保存为 openvpn.php，上传到 Serv00 服务器上即可使用
[完整 PHP 代码: 含 AUTH_TOKEN 鉴权、1 小时文件缓存、抓取 VPNGate iPhone CSV → base64 解码 → 解析 .ovpn → 拼成 Mihomo proxies YAML；过滤 public 节点、丢弃 UDP 节点]
当然这些家宽节点在国内大概率无法直连 这就需要自己找个前置节点，至于去哪里搞到线路好还便宜的节点那是另外一篇帖子了，这里不展开讲 找好前置节点后，配置好规则分组，导入到自己熟悉的客户端就可以使用了。
[示例 mihomo 配置: proxy-providers provider1 interval 3600 override dialer-proxy 你的前置节点 path ./provider/openvpn.yaml type http url https://789.nx.kg/openvpn.php?token=JJmi1vwutFHfssyH8Ym88NQNp2pZQ6Lo]
我比较懒，就不写规则分组了，将以上配置直接导入到 Pandora-Box 可直接使用，这个客户端直接支持不写规则分组导入节点或者配置
最终效果：节点列表、ping0.cc 质量、速度测试截图
订阅地址: https://789.nx.kg/openvpn.php?token=JJmi1vwutFHfssyH8Ym88NQNp2pZQ6Lo （拿去拿去）
题外话：这种方法不是使用 Serv00 搭建节点，不会封号，放心
