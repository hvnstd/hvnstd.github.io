OP（WsThanhDieu 清耀，首次发帖）1 小时前：
最近在测试一个越南开发者做的 LLM API，感觉还挺有意思，分享一下。
https://api.wusrouter.com/
目前可以看到 40+ 个模型，支持 OpenAI Compatible API，可以自定义 Base URL。
大部分模型可以免费使用，GPT 和 Gemini 目前有少量费用，其他模型暂时没有收费。
API：https://api.wusrouter.com/v1
如果有需要测试不同 LLM API 的朋友，可以自己试试看。
这是越南开发者做的项目，服务目前还在持续更新，模型和价格可能会调整，以实际情况为准。

john88（#2，1 小时前）：支持一下，感謝分享。

OP（#4，1 小时前）：是的，是越南程序员开发的。40 多个免费模型，只有 Claude 会收一点费用。
wabxn514（#10，1 小时前）：claude 全系收费、gemini 全系收费；chatgpt 和 grok 只有图里这些免费；国产 deepseek V4 flash、kimi K3、千问 3.8 27b、glm 5.3 flash 免费（附免费列表截图）。
OP（#13，1 小时前）：对，GPT 和 Gemini 以前网页端免费，后来被滥用刷接口，现在收费了。其他模型目前全免费。
