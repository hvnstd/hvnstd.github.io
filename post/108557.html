问题是它只有网页版，没有 API。我写了个 kuku2api 把它转成标准 OpenAI 兼容接口，任何 OpenAI 客户端直接就能用：
POST
顺手还带了一个每日签到/领积分的调度器，默认每天 9 点和 21 点自动跑，把"每日登录"和"完成一次对话"两个奖励领掉（幂等，领过不会重复）。
项目地址：
"GitHub - xinxinshuhao-create/kuku2api: OpenAI-compatible API for the GenFlow Pro web workbench, with a daily check-in scheduler · GitHub 2"
功能：
"- OpenAI 兼容 /v1/chat/completions，支持流式"
"- /v1/models 列出 14 个可用模型"
"- 签到接口：/signin/status、/signin/run、/signin/schedule"
"- 默认签到时间 9:00 / 21:00，可配置，也能关掉改成纯手动"
