如何注册诸如@outlook.sg/jp/my/it/kr/vn等之类的海外后缀？

https://www.nodeloc.com/t/topic/86665 · n/email
午间·21:35 |27 分 |90 评论 |by JinMukun

作者不推荐 Outlook，但给出了多个国家/地区 signup.live.com 直链（含 JA-JP、KO-KR、AU-AU、AT-AT、BA-BE、Br-Br、fr-fr、in-in、it-it、my-my、nz-nz、sg-sg、es-es、vn-vn 等），通过这些区域链接可注册海外后缀 Outlook。推荐开代理。

原文摘录

诸如 @outlook.sg/jp/my/it/kr/vn 等海外后缀。先说一下，很不推荐 Outlook，个人感觉是用过最烂的邮箱。其实注册海外后缀很简单，推荐开启代理。给出多个区域 signup.live.com 直链（JA-JP / KO-KR / AU-AU / AT-AT / BA-BE / Br-Br / fr-fr / in-in / it-it / my-my / nz-nz / sg-sg / es-es / vn-vn 等），可注册对应国家后缀。还有很多，各位可自行探索。
