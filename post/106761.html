1panel 原创教程：薅免费域名 → DNS 托管到 Gcore → 接入 tinkmail/oqumail 自建邮箱，0 成本获得专属后缀邮箱。步骤含 NS 记录、MX/TXT 记录配置、SPF/DKIM/DMARC。

原文摘录

1panel 原创小白向教程。需要有手。

1、第一步先去薅个域名（论坛友情链接里有大量免费域名汇总：https://www.nodeloc.com/projects?category_id=2 ）
1.1 选一个短的（如两位字符）
1.2 填写两个 NS 记录

2、将域名托管到 Gcore（https://gcore.com/ 注册账号 → DNS 管理 → 添加区域）
2.1 添加域名 → 拿到 NS 记录
2.2 把两个 NS 值填回步骤 1.2
2.3 看到『已委托』即可

3、将域名指定到免费邮箱服务
3.1 推荐 tinkmail.me（10GB 免费 / 安全反垃圾） 或 oqumail.com（最多 15 个邮箱 / 含 SPF/DKIM/DMARC 引导）
3.2 添加域名 → 复制 DNS 记录
3.3 在 Gcore 添加 DNS：只有两个类型是 MX，其他都是 TXT
3.4 等 Active 验证
3.5 添加自定义邮箱成员
3.6 退出当前账号，用新邮箱登录

总结：果然免费的都是最贵的啊，每一个步骤都需要注册。当然如果你提前准备好了域名，那只需操作第 3 步就很快。
