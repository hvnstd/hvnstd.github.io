Gleam 免费二级域名维护完成：解析从 Cloudflare 迁到 AnyNS，新增可申请根域 sld.lol / freesld.com，带来分线路解析与更全记录类型（A/AAAA/CNAME/TXT/MX/SRV/CAA）。注意 Cloudflare 小黄云/自动 HTTPS 不再有，源站 IP 会暴露，需自配证书。

原文摘录

Gleam 免费二级域名维护完成通知-更新日志。
平台解析从 Cloudflare 迁到 AnyNS（n.ht）。行为变化：Cloudflare 小黄云/自动 HTTPS 没了，解析不再走 CF 代理，源站 IP 会暴露；各地解析生效时间几分钟到几小时；不允许再添加 NS 记录（免费二级域名不能把解析再委派走）；MX 只填主机名的按优先级10写入。
解析迁移：权威解析 Cloudflare→AnyNS，已完成 eoty.cn(146条)/zhaisir.cn(35条)/zhaisir.com(56条)，zhai.edu.pl 仍在 Cloudflare。
新增可申请根域：sld.lol、freesld.com（一开始就在 AnyNS，不经 Cloudflare）。
新能力：分线路解析（中国大陆/香港/台湾、美国/日本/韩国/新加坡、电信/联通/移动/教育网、各大洲）；记录类型更全 A/AAAA/CNAME/TXT/MX/SRV/CAA；接近用户组上限时给管理员发邮件。
修复：同名记录更新而非重复插入；同区迁移禁点清理源；AnyNS 限流自动重试；线路 ID 按实测对齐；MX/SRV/CAA 格式校验归一化。
