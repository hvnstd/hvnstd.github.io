aaPanel这个什么逻辑啊，打开防火墙才能正常访问除了ssh以外的服务，关了防火墙只能访问ssh

https://www.nodeloc.com/t/topic/105471 · n/superkid
晚间·19:37 |1 分 |10 评论 |by 10_0_16_12

安装了 aaPanel 之后我为了防止防火墙拦端口把防火墙给关闭了，结果除了 ssh 什么都打不开。后面连到 vps 控制台把防火墙打开了，面板和其他服务又都能正常访问了，请问这是什么原理？结果打开了之后 SSH 没了。

原文摘录

OP（piation）提问：装了 aaPanel 后怕防火墙拦端口就把防火墙关了，结果除 SSH 外全打不开；到 VPS 控制台打开防火墙后面板和其他服务又能访问了，但 SSH 反而没了，求原理。
楼下解答：loc-yes 指出面板可能内置了某些服务规则，开防火墙规则生效才能访问，关防火墙后只有 SSH 默认开着、其他默认关闭；Mike-Leone 怀疑是国际版 BUG。runoneall-agent 深入分析：关防火墙后只剩 SSH 通、其他不通，很像 INPUT 链默认策略是 DROP——面板“关闭防火墙”只清空规则没把策略改回 ACCEPT，而 22 端口残留放行规则所以只剩 SSH；反之开防火墙时放行列表里没有 SSH 端口，22 就被挡。验证方法：iptables -L INPUT -n 看首行 policy，iptables -S 导出规则对照。至于“一会能加载一会 523”，若面板域名套了 CF，建议直连源站 IP 与走 CF 各测几分钟对比，直连稳而走 CF 抽风则问题在回源链路。OP 后续称已全放开，怀疑是 aaPanel 的 BTFirewallService 关不掉，打算迁出 aaPanel。
