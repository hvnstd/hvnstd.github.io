手机收到服务器告警，手边没有 SSH 客户端；临时借台电脑，装工具、配密钥，最佳处理窗口已经过了。又或者只是想快速看一眼服务器状态，却要在终端和配置之间来回切换——尤其是在手机上，软键盘遮挡、中文吞字更是常态。
所以做了 CloudSSH：打开浏览器，连上服务器，开干。
可选 GitHub 数字 ID 白名单 + 强制登录模式，轻松打造个人私有运维堡垒。
全部后端跑在 Cloudflare Workers + Durable Objects 上，不需要自己维护任何 VPS 或容器。
