原文摘录

我有一个朋友，朋友是谁就不说了。这位朋友前几天贪便宜从 deluxhost 入手 2核4G，找商家免费升到5G，无限流量。结果 ssh 连不上，ipv4被ban，改 ssh 端口 2222 才通。apt update 卡死，iostat 显示 vda 写等待 986ms / d_await 6216ms / aqu-sz 堆 3.33，磁盘超售。解决方案：把 /tmp 等高频写目录挂载为 tmpfs 内存盘（mount -t tmpfs -o size=512M tmpfs /tmp）；用 podman 拉起 debian 容器，podman commit 固化镜像，podman save 打成 .tar；rclone 推送到 webDAV 网盘备份；开机先 rclone 拉最新 tar，podman load 后直接拉起。整台 2C5G 烂盘小鸡靠内存盘+网盘快照流反而跑得最轻盈。还可挂网络硬盘或 systemd-nspawn 等替代方案。
