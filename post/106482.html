最近搞的esim记录

https://www.nodeloc.com/t/topic/106482 · n/sim
午间·16:01 |1 分 |7 评论 |by Amiya_desi

OP 分享最近白嫖/购买的几张 esim 使用体验：Jetpac 免费旅行卡（Google Maps/WhatsApp/Uber/Grab 无限+100MB 通用）、乌龟卡（4 欧，号段 5319，能接 OpenAI 短信但收不到 WhatsApp）、saily 美号抽到 943 号段（可接 X/TG/PayPal）。

原文摘录

OP（Amiya_desi，2 天前）汇总最近搞的几张 esim 流水：
- Jetpac：免费旅行 esim（Google Maps / WhatsApp / Uber / Grab 无限流量 + 100MB 通用），搞起来很简单；
- 乌龟卡：提前花 4 欧买的，号段 5319，能直接收 OpenAI 短信但接不到 WhatsApp 也不能收 WhatsApp（且目前 OpenAI Plus 已不要求接码）；
- saily：抽到美号 943 段，能接码 X / Telegram / PayPal，但不能接 WhatsApp，OAI 也只能通过 WhatsApp 接码，OP 评价「感觉有些废」；
- 目的：提前养号池（已填 3 个 free），注册 TG 小号，X 还未尝试。

关键回复：
- sydney1：用 esim 接 OpenAI 吗，像注册这些东西我都找接码平台的；
- Ricardo：现在有啥高性价比的 OpenAI 接码的，我用 heros 但 20min 限制 + 连续接码不发码；
- Ricardo：自己养沃达丰、德国 o2（未激活过期）、dito、英国 lyca 等多张 esim；
- James：我也 7、8 张 esim 了，养号一年要不少钱；
- 小米粥：英国沃达丰也还可以，楼主俺跟你一样乌龟卡 + saily 都搞了。
