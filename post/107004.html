原文摘录

登革热越过传统热带：
- 截至 2026-09-02，ECDC 记录法国 5 例 / 意大利 3 例本土感染登革热（不是输入病例）。
- 法国本土传播点：Mouleydier、Sète、Carmaux、Marseille 等；Sète、Marseille 截至最新报告仍活跃。
- 意大利本土传播簇：南部 Alliste、托斯卡纳 Piombino。
- 关键物种：白纹伊蚊（Aedes albopictus / 亚洲虎蚊）。
- ECDC + EFSA 2026-06 监测：截至 4 月，白纹伊蚊已在欧盟 / 欧洲经济区 384 个区域行政单元建立种群；意大利 107/107 监测区域、法国 83/101、西班牙 33/59、希腊 / 克罗地亚 / 保加利亚 / 德国均已建立稳定分布。
- 传播链：流行区感染者 → 航空旅行 → 当地白纹伊蚊叮咬 → 蚊体内病毒复制 → 叮咬下一个人 → 本土病例。
- 决定因素：温度——登革热病毒在蚊体内有外潜伏期，温度高则复制更快，更易在蚊死亡前到达唾液腺传播。
- 现状：ECDC 2026 夏季风险评估指出，许多已建立伊蚊种群的地区环境条件适合蚊虫活动 + 登革热复制，未来数周仍可能出现本土病例。
- 趋势：随气候变暖 + 白纹伊蚊北扩，瑞士巴塞尔已在本地捕获蚊虫中检测到登革热病毒，更高纬度传播可能性增加。
