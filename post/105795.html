论坛广告被挂马跳转到博彩网站

https://www.nodeloc.com/t/topic/105795 · n/suggestion
晚间·19:42 |1 分 |19 评论 |by mike-leone

点击论坛 cstonecloud 广告跳转到高仿 AWS 控制台域名的博彩站；商家复盘为 nginx Lua 注入 + 宝塔 WAF 篡改，仅针对移动端 302 跳转

原文摘录

OP（Mike Leone）报告：点击论坛 cstonecloud 广告跳转到高仿 AWS 控制台域名的博彩网站，再次访问又恢复正常，判断不是 DNS 劫持（本地用 DOH，且域名很像 AWS）。商家 cstonecloud 事后发布安全事件复盘：攻击类型 = nginx Lua 模块注入 + 宝塔 WAF 插件篡改；攻击链在 /www/server/nginx/conf/proxy.conf 注入 access_by_lua_file，创建恶意 /www/server/nginx/html/waf.lua，并篡改 /www/server/btwaf/waf.lua，检测移动端 User-Agent 返回 302 跳转到轮换恶意域名（sdflkj4978lj4yh.cyou、vio48sdlvnep7u.xyz 等），使用字符串反转技术逃避检测，设 cookie k=260830 防重复跳转，仅针对移动端（iPhone/Android）。修复措施：删除 proxy.conf 恶意加载指令、删除 waf.lua 恶意脚本、清理被篡改的 btwwaf、移除文件不可变属性、重载 nginx；备份 /www/server/nginx/conf/*、html/*、btwaf/*。验证：iPhone/Android/桌面 UA 均恢复 HTTP 200，恶意 cookie 不再出现。
