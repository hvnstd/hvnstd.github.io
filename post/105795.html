论坛广告被挂马跳转到博彩网站

https://www.nodeloc.com/t/topic/105795 · n/suggestion
晚间·18:02 |1 分 |15 评论 |by Mike-Leone

Mike-Leone 反馈点击论坛 cstonecloud 广告跳转到高仿 AWS 控制台域名的博彩网站（再次访问又正常，不像 DNS 劫持）；cstonecloud 随后回应“安全事件已修复”：系 nginx Lua 模块注入 + 宝塔 WAF 插件被篡改，针对移动端 UA 302 跳转到轮换恶意域名（如 sdflkj4978lj4yh.cyou、vio48sdlvnep7u.xyz），已清理并验证各端恢复正常。

原文摘录

Mike-Leone @James：点击 cstonecloud 广告跳转到一个高仿 AWS 控制台域名的博彩网站，再次访问又恢复正常，不像 DNS 劫持（本地用 DOH，域名很像 AWS）。James 初判为本地运营商 DNS 劫持，建议无痕/换 DNS 复测；后改口“也可能是网站被入侵，第一次访问跳菠菜，之前 bt 破解版后门就这么干”。jjfn1980“网站被黑可能性大一些”。
cstonecloud（认证商家）回应“安全事件已修复（宝塔AI立大功）”：攻击类型 nginx Lua 模块注入 + 宝塔 WAF 插件篡改；攻击链——在 /www/server/nginx/conf/proxy.conf 注入 access_by_lua_file，创建恶意 /www/server/nginx/html/waf.lua，篡改 /www/server/btwaf/waf.lua；仅针对移动端 UA 返回 302 跳转到轮换恶意域名、设 cookie k=260830 防重复跳转、用字符串反转逃避检测。修复：删除恶意加载指令/脚本、清理被篡改 WAF、移除文件不可变属性、重载 nginx；备份 proxy.conf/html/btwaf；验证 iPhone/Android/桌面 UA 均 HTTP 200 正常、恶意 cookie 不再出现。
