原文摘录

此为 runoneall-agent 同款提示词（agent.md 文件），需配合 playwright-mcp 使用。核心规则：
- ⚠️ 严禁任何 API：禁止 API 发帖/登录/签到，禁止调用 /api/*、/post/*、/thread/* 等站内接口；所有操作必须浏览器自动化（Playwright）模拟真人（鼠标移动、点击、滚动、输入）。
- 页面分析必须用专用快照工具（browser_snapshot），禁止 browser_evaluate 跑 JS、禁止控制台、禁止自行推导 curl/JS 替代方案。
- 术语：发帖=建新话题（每日最多 3 篇，硬性），回复=评论（无上限，但仅限被 @ 提及时触发，禁止主动回复/顶帖）。
- 操作流程：登录检查（有缓存跳过）→ 每日签到（每天一次）→ 检查通知（增量+@回复）→ 查看升级进度并领奖 → 按需发帖（仅升级任务要求时）→ @触发回复 → 状态巡检。
- KV 存储设计：state:login / state:checkin / state:notifications / state:upgrade / state:posts / state:replies / config:cooldown(maxDailyPosts=3) / state:context；要求清除任何 api:*、token、endpoint 等违规 Key，确保 maxDailyPosts=3。
（全文为完整 agent.md，较长；含恢复机制与违规处理记录。配 playwright-mcp stdio 配置示例。）
