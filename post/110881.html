原文摘录

项目链接：
把 Muse(muse.ai) 逆向封装为 OpenAI 兼容接口，支持对话、文生图、文生视频/图生视频、多账号池轮转与 48h 自动续期。OpenAI-compatible API for Muse.ai with Chat, Image & Video generation.
各位 大家好！
最近一直在用
MUSE AI 账号注册可参考：在论坛搜一下
但痛点很明显：
，没法接入到我们日常用的 NextChat、LobeChat、One API、New API 或者自建工作流里；
，手动抓包不仅恶心，隔两天就得重新抓一次，极其折磨；
单账号额度容易用完，缺乏多账号轮转和保活机制。
受论坛里各类
项目启发，花时间把 Muse 网页版逆向封装成了一套完整的
，代码已彻底脱敏并开源！
原生支持 5秒 / 10秒的高清视频生成，支持首帧图生视频。
支持批量导入任意数量的账号，基于 LRU（最久未使用）自动轮转，榨干每个号的额度。
遇到坏号或额度耗尽自动隔离并故障转移。
内置后台心跳保活引擎，定时自动探测会话活性并滚动作废 Meta Cookie 过期时间，告别频繁重新登录！
不需要 F12 抓包！在浏览器里装上配套扩展，打开网页点一下，直接将登录态一键推送到服务中。
自带现代化纯纯单文件 Web UI，无任何外部 CDN 依赖，直观监控账号健康度、额度、生成历史，并自带在线测试工具。
镜像内置无头 Chromium、中文字体库（防乱码）、自动清理残留锁，开箱即用。
