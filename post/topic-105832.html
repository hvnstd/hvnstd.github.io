NodeLoc 设备信息显示功能分析报告（日期 2026-08-30）

目标：实现 NodeLoc APP 发帖时显示设备信息的功能（如"来自 Pixel 8 Pro"）。

逆向分析结果：
1. 官方 APK 反编译发现：在 defpackage/y6.java 第 389-409 行找到关键代码，根据 post_source_level 在发帖 body 添加 mobile_source_platform / mobile_source_brand / mobile_source_model 字段。
2. 发帖请求参数：Level 1+ 添加 mobile_source_platform "android"；Level 3+ 添加 mobile_source_brand（品牌名如 Google）；Level 4+ 添加 mobile_source_model（型号如 Pixel 8 Pro）。
3. 品牌获取逻辑：在 defpackage/ow0.java 中实现，优先从系统属性读取市场名称（ro.vivo.market.name、ro.product.marketname、ro.config.marketing_name 等），子品牌列表 {iqoo, redmi, poco, realme, honor, nothing} 特殊处理，否则用 Build.MANUFACTURER。
4. Web 页面显示方式：HTML 结构 <span class="mobile-source"><span class="mobile-source__badge" title="本帖由 lezi-fun 使用 Pixel 8 Pro 发送。">Pixel 8 Pro</span></span>，显示文本为 "Pixel 8 Pro"。

测试结果：通过 curl 模拟发帖（带 mobile_source_platform/brand/model 及 CSRF Token）成功，Web 页面设备信息正确显示为 "Pixel 8 Pro"。

参考资料：官方 APK v1.1.3（github.com/nodeloc/app）、测试话题、反编译工具 jadx。
