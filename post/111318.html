最近几天meta公司推出了muse这个超级app热度直逼年初的“小龙虾”。下先介绍一下MUSE：Muse 是 Meta 的个人 AI Agent，可以浏览网页、、移动设备对话、生成文件，部分任务在关闭 App 后仍能继续，真就随时随地帮你完成任务。当注册 muse.ai 可以获得 muse 模型的每周额度，还可以获得一台 2 核 8G 100G SSD 的 VM这就大大提升了可玩性，搭配保活看门狗程序实现理论上的永久免费vps
一个干净的美国家宽 IP（机场那种万人骑的可能不行 ）实测Google Spark分配的节点可用，自动分配的台湾机房节点也能成功
年龄验证(绑卡)—非必须
MUSE注册地址：muse.ai 有桌面端和移动端app
开始前知道这几件事就够了：
官方 9 月 8 日的公告宣布首发面向美国，支持 iOS、Android 和网页端。你的账号当前能否使用，以注册页面为准。
官方提供免费使用与付费订阅，具体额度和价格看账号内的说明。先试一个任务，再决定是否订阅。
本文用 Muse 桌面端做示范，先选一个设备跟着做即可。
如果进不去，先看页面具体提示。地区未开放、账号不符合条件和网络连接失败，需要分别处理。

要是使用老号Facebook的话很多可以直接跳过年龄验证（不需要绑定银行卡）就可以注册成。
登录后会看到赠送的额度，每周重置。

Cloudflare Worker 监控后台（CF Server Monitor）
探针，每 60 秒上报心跳
三层保活：沙盒内看门狗 cron + 平台定时巡检 + 平台开机钩子
Hermes 微信机器人（微信扫码绑定）
一步一步跟着提示走，中间省略cf配置细节。这样就得到一个VM沙盒虚拟机了
由于它没有公网IP这个时候需要做内网穿透，有自己的vps的可以用自己vps反代或者使用cloudflare隧道
直接用muse安装

muse-reverse-ssh：给没公网 IP 的机器（沙盒、云 VM、家用服务器）建反向 SSH 隧道，把它变成可从公网连的 SSH 服务器，带保活守护和排错手册——我们刚才隧道部分就参考了它的方案。
grok-search：联网搜索、查最新事实、抓网页内容。
evidence-driven-bugfix：修 bug 用的"证据优先"流程，先复现证据再动手改。
best-project-memory：项目级记忆管理，开工时恢复上下文、记录决策、保存进度。
codex-agent-worktree-setup：给 Codex 等 agent 建隔离的 git worktree 开发环境。
awesome-ui-kit：构建 AI 原生 Web 界面、聊天应用、RAG 搜索页等用的单文件 Web 组件库。
obsidian-doc-router：Obsidian 知识库的文档路由器，读写/改笔记前先查规范入口。
production-code-quality-review：按生产级标准评审 PR、diff、架构变更和上线风险。
split-image-assets：把一张图拆成带透明通道的独立图层资产包（精灵图、蒙版、背景清理、元数据）。
