前言：感谢 @runoneall 提供灵感，感谢 @James 同意开发。

我把 NodeLoc 做成了一个 MCP，装进 Claude Desktop、Cursor、Cherry Studio、Cline 这些客户端后，直接用自然语言操作论坛：
- “看看最新帖子”
- “给我签到”
- “在这条帖子里发个 100 能量、10 份的红包”
- “给这篇帖子的作者打赏 50 能量”

一共 42 个工具，分几块：
- 论坛常规：浏览最新/热门/分类、读帖、发帖、回复、私信、点赞、收藏、投票
- NodeLoc 特色：嵌套社区(Node)浏览/加入/创建、聊天频道、每日签到、发红包、打赏能量、积分明细/榜单
- 官方支付 API：创建支付、查询订单、能量转账（需在 payment/applications 申请应用）
- 知识库：检索 docs.nodeloc.com 文档（基于 llms.txt 索引）
- 小程序：nodeloc-apps CLI 的封装
- 鉴权走 Cookie 会话（希望 @james 能开放一下 user-api-key）：登录后会话持久化到本地，过期自动重新登录；支持 2FA

配置很简单（环境变量）：
NODELOC_USERNAME=你的用户名 NODELOC_PASSWORD=你的密码 node dist/index.js

纯本地运行，不用担心账号泄露。仓库：GitHub - Patrick130306/nodeloc-mcp（MCP server for the NodeLoc community: forum, energy, payment, docs, miniprogram tools，双语 README，MIT）。求求给孩子几个 star 吧。
