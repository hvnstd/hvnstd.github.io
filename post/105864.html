M365-Copilot2API v0.6.5 正式发布

https://www.nodeloc.com/t/topic/105864 · n/m365-copilot
晚间·18:03 |12 分 |31 评论 |by 贺煦修

M365-Copilot2API v0.6.5 发布：新增 API Key 多账号绑定与故障切换、限流/额度快照展示、Responses 与工具调用兼容增强、WebSocket/重试稳定性改进、WebUI 中文乱码修复；暂时下线 M365 批量建用户入口。

原文摘录

楼主 贺煦修（user80）发布 M365-Copilot2API v0.6.5 正式版，主要更新：①账号调度与故障切换——API Key 可绑定一个或多个出口账号，绑定账号限流/认证失败时在其他绑定账号间切换，修复越权使用未绑定账号的问题；②限流与额度状态——优化冷却/恢复检测，WebUI 明确标识“上游额度快照”，冷却提示改为“X 分钟后再次检测”；③Responses 与工具调用兼容——改进参数处理、完善 call_id/流式事件/错误映射，新增 /responses 对 /v1/responses 的兼容入口；④网络与稳定性——改进 WebSocket 关闭与慢消费者处理，网络错误不再自动重放非幂等 POST，本地过载返回明确 503；⑤WebUI 修复中文乱码、增加多账号绑定管理；⑥暂时禁用 M365 批量创建用户前端入口（代码保留，后续可恢复）。发布地址为 GitHub release v0.6.5。目前 12 赞、31 回复、162 浏览。
