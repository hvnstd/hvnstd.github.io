M365-Copilot2API v0.6.5 正式发布

https://www.nodeloc.com/t/topic/105864 · n/m365-copilot
晚间·19:38 |12 分 |32 评论 |by user80

v0.6.5：账号调度与故障切换、限流与额度状态、Responses/工具调用兼容、网络与稳定性、WebUI 改进；暂时禁用 M365 批量创建用户入口

原文摘录

本次正式发布的 v0.6.5 主要更新：账号调度与故障切换（API Key 可绑定一个或多个出口账号，绑定账号限流/认证失败时在其他绑定账号间故障切换，修复越权使用未绑定账号问题，显式选择未绑定账号返回明确权限错误）；限流与额度状态（优化限流/冷却/恢复检测，冷却结束采用受控探测，WebUI 将额度标识为“上游额度快照”）；Responses 与工具调用兼容（改进参数处理、完善 call_id/流式事件/错误映射、增加 /responses 对 /v1/responses 兼容入口）；网络与稳定性（改进 WebSocket 关闭与慢消费者处理，非幂等 POST 网络错误不再自动重放，本地过载返回明确 503）；WebUI（修复中文乱码，增加 API Key 多账号绑定管理）；暂时禁用 Microsoft 365 批量创建用户前端入口及相关 Graph 后端路由。正式版地址：github.com/HEXUXIU/M365-Copilot2API/releases/tag/v0.6.5
