零框架 · 零构建 · 零依赖 —— 双击 index.html 就能用的个人博客，也可以一键部署到 Cloudflare 免费上云

原文摘录

硬干货原创项目。Qingyu'Blog 是 kejiland 开发的纯原生 JS 博客系统（零框架/零依赖）：整个博客=4 文件（index.html + style.css + app.js + posts.js），双击 index.html 离线即用，无需 npm install；也可一键部署到 Cloudflare Workers + D1（免费额度），GitHub Actions 自动部署。核心功能：Markdown写作台（草稿不丢）、PBKDF2+AES-GCM 端到端文章加密（正文只存密文，列表接口也屏蔽）、D1 全局评论（XSS全转义+SQL参数化+IP限频+Origin校验）、管理员 PBKDF2-SHA256 加盐哈希（10万次迭代）+ 7天会话令牌 + 5次失败锁15分钟 + 一次性 setup key 防抢注。阅读体验：卡片列表、深色/浅色切换、TOC、代码高亮（js/ts/py/bash/css/html/json）、站内搜索、归档/标签云/上一篇下一篇。分发：RSS（加密文章自动排除）+ Sitemap 自动生成。测试：68 项回归（node smoke-test.js 零依赖）。仓库 https://github.com/kejiland/qingyu-blog ，在线 Demo https://kejiland.2024921.xyz/ ，MIT 协议。技术栈：原生 JS ES5 / Cloudflare Workers + D1 + KV / PBKDF2 + AES-GCM / Markdown 文件双通道。46赞高赞帖。
