我把smailr做成mcp了！！！

https://www.nodeloc.com/t/topic/105821 · n/program
午间·13:33 |3 分 |7 评论 |by patrick0306

把 Smailr 邮件服务做成 MCP，Claude/Cursor/Cherry Studio/Cline 可用自然语言操作邮箱（列邮件、发信、查配额等），内置 NodeLoc OAuth 登录，免手动建 key。

原文摘录

最近kimi的额度重置了，然后想着，反正额度放着也是浪费，把 Smailr(https://smailr.com)的邮件服务做成了mcp。装完之后，Claude Desktop、Cursor、Cherry Studio、Cline 这些客户端就能直接用自然语言操作邮箱了，比如：列出收件箱最新5封邮件、用指定域名给某人发信、查存储配额。目前实现了 23 个工具，覆盖 Smailr 全部 API：邮箱增删改查、邮件列表/详情/搜索/发送、附件上传、联系人、文件夹、标签，以及收信规则、签名、配额、统计等只读接口。最省事的是登录：内置 NodeLoc OAuth，跑 `npx smailr-mcp auth` 走授权后自动创建 scoped API key 并打印 MCP 配置。本地优先（stdio 跑在本机，key 不经第三方），依赖极少（仅官方 SDK + zod）。已知限制：Smailr 无响应 schema（原始 JSON 透传）；联系人/文件夹/标签只支持列表和创建；无 webhook，新邮件需轮询 list_mails。项目地址：https://github.com/Patrick130306/smailr-mcp ，MIT 协议，欢迎 star/issue/PR。
