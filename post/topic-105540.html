额，先拿之前训练的190.5M的模型玩一下

早间·07:05 |2 分 |2 评论 |by 贺煦修

这个是之前清洗数据完成之前的，所以说有乱码

原文摘录

这个是之前清洗数据完成之前的，所以说有乱码。

训练量严重不足：checkpoint 只训练了 4,194,304 tokens，对约 190M 参数模型只是一次流水线验证，通常需数十亿 token 才能形成基本语言能力。数据单一且类型不对：train.bin 仅来自 belle_train_2m_cn.jsonl 的 229,339 条记录，BELLE 是指令数据，不适合作为基础预训练主料，模型反复生成模板化内容。GPT-2 tokenizer 不适合中文，生成末尾出现乱码。验证 loss 有误导性（训练/验证集同分布）。

实测：中文续写能生成结构但语义不连贯；英文续写漂移到 Python 代码；12+7 未答 19；Fibonacci 输出 64 个空格；中国首都未答北京。冷启动首 token 约 7.23s，预热后约 15–65ms、约 62–66 token/s。

价值主要是证明训练/FP16/checkpoint 恢复/推理链路能跑通，仅此而已；后续肯定没这么烂了。
