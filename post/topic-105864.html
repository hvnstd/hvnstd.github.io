M365-Copilot2API v0.6.5 正式发布

晚间·21:33 |8 分 |17 评论 |by user80

本次正式发布的 v0.6.5 主要包含以下更新：支持 API Key 绑定一个或多个出口账号；绑定后的 API Key 只会在指定账号范围内调度；某个绑定账号限流或认证失败时，可在其他绑定账号之间故障切换。

原文摘录

本次正式发布的 v0.6.5 主要包含以下更新：

账号调度与故障切换：支持 API Key 绑定一个或多个出口账号；绑定后的 API Key 只会在指定账号范围内调度；某个绑定账号限流或认证失败时，可在其他绑定账号之间故障切换；修复故障切换可能越权使用未绑定账号的问题；显式选择未绑定账号时返回明确的权限错误；流式、非流式及工具调用路径统一遵守账号绑定范围。

限流与额度状态：优化账号限流、冷却和恢复检测逻辑；冷却结束后采用受控探测，避免多个请求同时冲击上游；WebUI 将额度明确标识为上游额度快照；限流或冷却状态优先于历史额度显示；冷却提示改为"X 分钟后再次检测"，不再承诺届时一定恢复。

Responses 与工具调用兼容：改进 Responses 请求参数处理；完善工具调用的 call_id、流式事件及错误映射；修复重复工具调用 ID 和部分工具状态关联问题；加强不同客户端、请求和会话之间的隔离；增加 /responses 对 /v1/responses 的兼容入口。

网络与稳定性：改进 WebSocket 连接关闭和慢消费者处理；非幂等 POST 请求发生网络错误时不再自动重放；Retry-After 同时支持秒数和 HTTP 日期格式；优化账号池扫描、并发控制及本地过载处理；本地过载返回明确的 503，不再误标为上游限流。

WebUI：修复中文乱码及异常替换字符；两份 WebUI 嵌入资源保持一致；增加 API Key 多账号绑定管理能力；优化账号状态、额度快照和冷却信息展示。

暂时禁用：暂时禁用 Microsoft 365 批量创建用户的前端入口；同时取消相关 Graph 配置、授权及批量创建后端路由；实现代码暂时保留，后续版本可以继续完善后恢复。

正式版本地址：https://github.com/HEXUXIU/M365-Copilot2API/releases/tag/v0.6.5
