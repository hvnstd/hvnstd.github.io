NodeLoc App 更新日志

这一版的核心目标是让 Android 客户端的行为全面向 Web 端看齐，彻底告别过去简陋的“本地纯文本时代”。部分功能我们还没有确定，但是做了，不知道做的是否准确。

项目地址：https://github.com/lezi-fun/nodeloc-app
下载链接：https://github.com/lezi-fun/nodeloc-app/releases/tag/v0.3.1

v0.3.0 → v0.3.1
这一版主要将编辑器预览、表情解析、图片渲染以及抽奖逻辑等核心功能从“前端本地模拟”改为了“服务端真实驱动”。不仅全面支持了 Markdown 原生预览与自定义表情，还针对业务中诸如用户资料空值、嵌套话题分页字段缺失、HTTP 422 业务错误等服务端真实返回的边缘场景做了大量的兼容与防崩溃处理。

发布日期：2026-08-29；更新规模：包含从 0f6b44b 到 1776f8a 的多项功能增强与问题修复。

新功能：编辑器支持服务端 Markdown 预览与附件上传；接入 NodeLoc 自定义表情面板；抽奖系统交互对齐 Web 端；帖子内容展示全面增强（支持 details 折叠、Onebox 卡片、全宽图片）；侧边栏与社区互动显示优化。

变更：外部链接增加安全拦截墙；App 后台版本更新检测；网络连接超时策略调整。

修复：多处服务端数据反序列化崩溃；编辑器操作无响应与附件参数缺失；第三方小程序白屏与抽奖 422 报错。
