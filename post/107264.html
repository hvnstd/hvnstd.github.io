好帖！
不知道你们是不是也这样：Termius里躺着几十个 VPS 脚本——DD 重装的、跑分的、测流媒体的、装 Docker 的……真到用的时候，滚动翻半天记录。网上也流传过一些"工具箱合集"，但基本都是硬编码的 shell，想加一条自己的脚本就得改源码，改完也没法分发到自己的其他小鸡上。
前几天GLM送了TOKEN，索性VIBE一个小工具，核心诉求就是自由定制自己的工具箱，2分钟就能上手开始使用。存放在Cloudflare，零成本。
：
在网页上维护你自己的脚本合集，一键生成一个单文件 Bash 工具箱；网页上改完，VPS 上
同步，一键安装命令永远不变。
网页上加了脚本、改了命令、禁用了条目，VPS 端一个
就同步到位，不用换安装链接、不用重装。收藏和自定义命令存在 VPS 的
里，更新不丢。
推荐 GitHub Actions 方式：Fork 仓库 → 配 3 个 Secret → Actions 页手动 Run，约 2 分钟流水线自动完成建库、建表、导种子、发布，全程跑在 Cloudflare 免费额度上，
。不想上云的还有 Docker Compose 自托管，数据完全留在本机
。
所有数据 base64 编码后内嵌进脚本，不存在引号转义和注入问题；危险条目（DD 重装这类）要手动输入
二次确认；需 root 的条目自动检查权限；任何脚本执行前都会先打印完整命令让你
。
Vue 3 + TailwindCSS 前端，Cloudflare Pages Functions + D1 后端，生产依赖只有
一个。MIT 开源；收录的第三方脚本版权归原作者所有，管理端每条都能跳回原仓库。
（GitHub Actions，约 2 分钟）：
Fork 仓库，到 Actions 页启用 workflows（Fork 默认禁用）
配 3 个 Secret：

、
（选填，不配则站点只读）
Actions 页手动 Run workflow，跑完得到
