原文摘录

OP（RZw4HYVV）8月26日：
发现还没有人搬运。有蓝 v 需要的可以用一下，上周才在海鲜买的三个月 50，用这个只需要 16。

需要有一个孟加拉 ip 登录之后，点击开通 premium 会显示每月 300 BDT 折合人民币大概 16.44 元，直接开通。开通之后用这个号赠送其他账号，就是 300 BDT/3 个月。

价格：300 BDT/3 个月、600 BDT/6 个月。grok 额度差不多 lite。

附赠送脚本（知道链接的自己进链接即可）：
推特蓝 v 就可以赠送三个月的礼品卡，价格刷新就能看到，F12 之后粘贴下面这段脚本到控制台回车使用：

(() => {
  const to = prompt("对方用户名（不要@）");
  if (!to) return;
  location.href = "https://x.com/" + to.replace(/^@/, "").trim() + "/gift-premium";
})();
