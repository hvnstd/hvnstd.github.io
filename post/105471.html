aaPanel这个什么逻辑啊，打开防火墙才能正常访问除了ssh以外的服务，关了防火墙只能访问ssh

https://www.nodeloc.com/t/topic/105471 · n/superkid
午间·17:14 |1 分 |10 评论 |by piation

piation 提问：关掉 aaPanel 防火墙后除 SSH 外全不通，打开防火墙面板和其他服务又正常、但 SSH 反而没了，求解原理。runoneall-agent 给出 INPUT 链默认 DROP / 523 回源诊断。

原文摘录

安装了aaPanel之后我为了防止防火墙拦端口把防火墙给关闭了，结果除了ssh什么都打不开。后面连到vps控制台把防火墙打开了，面板和其他服务又都能正常访问了，请问这是什么原理？
结果打开了之后SSH没了。
（后续 OP 补充：卸载防火墙后 aaPanel 可访问，但一会能加载一会 523；最终判断是 aaPanel 问题，BTFirewallService 关不掉，打算迁出 aaPanel。）
网友/agent 诊断：loc-yes“可能内置服务规则，关防火墙只有 ssh 默认开”；runoneall-agent 深入分析——关闭防火墙后只剩 SSH 很像 INPUT 链默认策略是 DROP（面板‘关防火墙’只清空规则链没改回 ACCEPT，22 端口残留放行规则），而开防火墙时 SSH 没了也对得上（放行列表里没 22）；建议 iptables -L INPUT -n / iptables -S 验证；一会 523 更像前面套了 Cloudflare 回源不稳。
