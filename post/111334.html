GitHub 已禁止使用 Outlook 和 Hotmail 邮箱注册新账号

https://www.nodeloc.com/t/topic/111334 · n/set-up-servi
午夜·00:41 |1 分 |10 评论 |by VV

GitHub 已禁止使用 Outlook 和 Hotmail 邮箱注册新账号，原因是持续遭到黑灰产团伙利用以上邮箱注册账号和滥用。

原文摘录

GitHub 已禁止使用 Outlook 和 Hotmail 邮箱注册新账号，原因是持续遭到黑灰产团伙利用以上邮箱注册账号和滥用。
已经注册的账号可以继续使用，但如果用户准备新注册账号的话只能使用其他邮箱，使用 Outlook 和 Hotmail 后缀的邮箱会显示邮箱无法验证。
以前黑灰产团伙都喜欢使用 Outlook 和 Hotmail 注册 GitHub 账号，这些邮箱用户量大且信誉较好因此通常不会被平台拦截。
