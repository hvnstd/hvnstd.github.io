原文摘录

今天我琢磨着做了一个Pi的插件项目：为 Pi 提供类似 Claude Code 的“对话与工作区同步回退”。 无需配置git，利用Pi 原生会话树。
功能：
双击 Esc 打开 Pi 原生会话树
每次发送用户提示词前自动建立 checkpoint
恢复代码和对话到同一个历史节点
仅切换对话，代码保持不变
仅恢复代码，对话保持不变
/redo-rewind 撤销最近一次恢复操作
/resume 或重启 Pi 后仍可使用 checkpoint
通过 Pi 会话节点 entryId 精确绑定快照与用户消息
使用 pi.appendEntry() 将 checkpoint 元数据写进 Pi 会话树
使用独立 shadow Git，不修改项目 Git 的提交、分支、索引或 reflog
可记录未跟踪文件以及 Shell 命令产生的普通文件变化
拒绝通过符号链接或硬链接恢复，防止写穿链接
每个会话最多保留 100 个 checkpoint
运行时中英文适配：中文系统显示中文，其他环境默认显示英文
npm 页面：
"Claude Code-style synchronized conversation and workspace rewind for Pi. Latest version: 0.1.2, last published: 10 days ago. Start using pi-claude-rewind in your project by running `npm i pi-claude-rewind`. There are no other projects in the npm..."
GitHub：
Claude Code-style synchronized conversation and workspace rewind for Pi
安装：pi install npm:pi-claude-rewind
开源共建～欢迎pull/push
