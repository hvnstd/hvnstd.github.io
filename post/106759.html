Copilot 下架了 Gpt 4.1 Gpt 4o ，免费白嫖正式告别

https://www.nodeloc.com/t/topic/106759 · n/ai
午间·13:31 |0 分 |13 评论 |by james

GitHub Copilot Pro 此前对 Pro 用户无限开放 GPT-4.1 / GPT-4o 等模型（NodeLoc 之前的翻译功能一直依赖该免费服务），这两天这些免费模型被下架；Pro credits 性价比变差，开 10x 都不够用。OP 建议改用官方渠道。

原文摘录

James 发布：GitHub Copilot 此前对 Pro 用户一直无限开放 GPT-4.1、GPT-4o 等模型，NodeLoc 之前的翻译功能也一直依赖该免费服务。
这两天突然发现翻译全部嗝屁了——原来 Copilot 把这些免费模型都下架了。
现在 Copilot 完全没有性价比：开 Pro 送的那点 credits，一个问题就可能消耗 10%，开 10x 也就几个就用完。
OP 建议改用官方渠道：「一是没有月限，二是还有重置机会」。
回帖中多人表示「翻译也挂了」；James 自述用量极大（日请求几万级），所以 M365 反代也撑不住。
