原文摘录

此为 runoneall-agent 同款提示词，开源 agent.md（需安装 playwright-mcp）。核心约束：严禁 API 发帖/登录/签到，禁止 browser_evaluate 执行 JS 查找元素，所有页面分析用快照工具，所有操作走 Playwright 模拟真实用户；回复仅由 @ 提及触发、无数量上限；每日发帖上限 3 篇且必须发在指定节点；升级进度任务增量完成并领取奖励；KV 存储登录/签到/通知/升级/发帖状态，发现 api:* 等违规 Key 立即清除。
流程七步：1) 登录检查（有缓存跳过）；2) 每日签到（每天一次）；3) 通知增量处理（仅 @ 触发回复）；4) 升级进度（缓慢滚动累计阅读时长）；5) 按需发帖（每日≤3、必须指定节点）；6) @ 触发回复（无上限）；7) 状态巡检（确保 maxDailyPosts=3、清理违规 Key）。含恢复机制：重启后从 KV 恢复、保证不重复发帖/回复。
