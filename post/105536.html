梳理 OpenAI Sites（ChatGPT 站点）的托管、费用与域名：公测期含在 Plus/Pro/Business 等套餐内，默认域名 <名>.openai.chatgpt.site，可绑自有域名，额度受限。

原文摘录

codex 中有一个「站点」，包含在订阅套餐中。不需要自备服务器、域名、数据库；公测期间，没有额外费用（前提是订阅用户）。

一、托管在哪里：Sites 生成的网站/Web 应用/浏览器游戏由 ChatGPT Sites 托管平台统一部署管理，不会自动部署到用户自己的 Cloudflare、Vercel 等。支持前端页面与一定程度服务端逻辑，提供 D1 数据库、R2 对象存储、身份认证、HTTPS 与 WebSocket。不支持原始 TCP 连接、长期后台服务及部分特殊框架；当前不提供数据驻留保证。

二、费用：公测期含在 Plus/Pro/Business/Enterprise/Edu 套餐中（Plus 20$/月、Pro 100$/月起、Business 20$/用户/月按年付、Enterprise/Edu 联系销售）。采用「套餐包含并受额度限制」模式，达额可能暂停新建/扩容/高流量公开。额外费用：自定义域名注册续费、OpenAI API Token 计费、第三方服务、ChatGPT Credits。

三、域名：默认 <站点名>.openai.chatgpt.site；站点名规则 ≥5 字符、小写字母开头、仅小写字母/数字/单连字符、不能以连字符结尾、不连续连字符。可绑定自有域名（需自行购买并加 DNS 记录）。

四、总结：适合快速发布官网、落地页、Dashboard、内部工具及轻量 Web 应用，主成本是 ChatGPT 套餐。
参考：OpenAI Sites 官方说明、OpenAI 官方价格说明。
