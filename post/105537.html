商汤日日新已上线kimik3+ZCode免费领取GLM-5.3-Flash模型3亿Token

https://www.nodeloc.com/t/topic/105537 · n/deal-hunter
晚间·22:10 |3 分 |19 评论 |by vv

coder1 整理商汤日日新上线 Kimi K3 / DeepSeek-V4 Pro 及 8/28 新积分规则，并预告 ZCode 周末送 3 亿 Token 体验额度活动（周五 20:00 至下周一 09:00，升级 3.10 后领取）。

原文摘录

商汤科技日日新上新了 Kimi K3 和 DeepSeek-V4 Pro。不过他 token plan 规则改了，现在 5h 刷新的是积分。TokenPlan 将于 8 月 28 日启用新的积分规则：所有已开放模型统一使用通用积分池，Flash-Lite 系列模型另享专属积分池。商汤的日日新链接：https://www.sensenova.cn/token-plan（附更新后额度截图）。
ZCode 周末送额度活动本周开启：本周五 20:00 至下周一 09:00，所有登录用户均可免费领取 3 亿 Token 体验额度，新用户、老用户、Coding Plan 订阅用户均可参加。
参与方式（三步）：1. 将 ZCode 升级至 3.10 最新版本；2. 登录 ZCode 账号（新/老用户、Coding Plan 订阅用户均可）；3. 周五 15:00 起在客户端左下角活动卡片点击「领取」。
活动规则：活动时间本周五 15:00 起开放领取，额度周五 20:00 生效，至下周一 09:00 到期（北京时间）；到期未使用部分自动失效，不可延期、不可折现。
