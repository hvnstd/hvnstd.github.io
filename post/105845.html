启动时自动检查 GitHub Release 最新版本，Material 3 风格更新提示对话框显示版本号和更新内容。点击"前往下载"后台下载 universal APK 并自动触发安装，支持版本号智能比较（x.y.z 格式）。后台下载进度通知，完成后弹出系统安装界面。新增
管理 GitHub API 集成与版本比较，
处理 DownloadManager + BroadcastReceiver，
提供 Material 3 对话框。添加 FileProvider 支持 Android 7.0+ APK 安装，新增
权限。（
"完整实现 Discourse MessageBus 长轮询机制，用于接收服务端实时推送的消息。支持 15+ 个频道类型订阅（/latest、/topic/{id}、/categories、/delete、/recover、/destroy、/global/asset-version、/file-change、/site/banner、/site/read-only、/private-messages 等）。自动重连机制（指数退避策略），话题详情页动态订阅，收到更新时自动刷新。新增"
实现长轮询客户端，
提供全局实例管理，
作为 Compose 组合本地变量。（
发帖时根据
设置自动添加设备信息（平台、品牌、型号）。话题详情页显示发帖设备徽章，圆角背景徽章样式与称号样式保持一致。新增
获取设备信息，
枚举定义显示级别，
渲染设备徽章。（
完整实现 OAuth 第三方登录流程，支持 Google、GitHub、Discord 等平台。新增
处理授权回调，
接收第三方登录结果，
管理登录状态与会话。登录页显示第三方登录按钮，点击后跳转授权页面，授权成功后自动返回应用并完成登录。（
新增设置页面，支持主题切换、通知设置、账号管理等功能。小程序 WebView 优化加载体验，支持加载进度显示、错误提示、刷新重试。侧边栏小程序列表完善，显示小程序图标、名称、描述。（
搜索页新增类型选择器，支持按话题、帖子、用户、标签等类型筛选搜索结果。发帖来源 API 集成，支持获取发帖设备信息配置，根据服务端设置决定是否显示设备信息。（
修正 User-Agent 字符串，完全模拟真实 Android Chrome 浏览器，包含完整的设备型号、Android 版本、Chrome 版本等信息，确保与官网后端兼容。（
修正签到请求格式，确保 POST 请求参数与官网后端完全一致，解决签到失败问题。同时修复签到后的响应处理，正确显示签到结果提示。（
修复表情选择器和 Markdown 预览功能，表情选择器按名称前缀正确分组，只显示 NodeLoc 自定义表情过滤系统表情。表情分组显示友好名称，提升用户体验。（
禁用侧边栏滑动手势避免误触，点击侧边栏用户头像可打开个人资料页面。（
